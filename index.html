File Format Guide

G-code (.gcode) — Supported. PrintFolio can read common metadata, settings, dimensions, filament data, and extrusion geometry.

BGCODE (.bgcode) — Supported for metadata and embedded thumbnails. Full binary toolpath decoding is still developing.

3MF (.3mf) — Supported for model geometry, dimensions, thumbnails, and project settings when those settings are present.

Cura UCP 3MF — Under testing. These are Universal Cura Projects containing a model plus a defined set of printer-agnostic settings.

Prusa 3MF — Under testing. Project contents and settings are being evaluated.

Other slicer formats — Future investigation.
