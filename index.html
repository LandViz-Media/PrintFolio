Material Library

Manage spools, materials, and printer-specific profiles from the Material Library button at the top of PrintFolio. The library is intentionally separate from this print inspection view.

Future: Reprint / Update

This will become a planning workspace for older prints: select a current material and printer, compare the original settings with the selected profile, and adjust temperatures, speeds, fan cooling, supports, infill, and other settings for a new print without altering the original print record.
